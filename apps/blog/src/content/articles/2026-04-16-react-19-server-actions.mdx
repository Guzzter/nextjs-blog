# Beyond API Routes

For years, we've relied on `fetch` calls to custom API routes to handle form submissions and data updates. React 19 introduces a standardized way to handle these interactions directly within your component tree using **Server Actions**.

## Simplicity by Design

Server Actions allow you to define asynchronous functions that run on the server but can be invoked from the client. This eliminates the need for manual endpoint management and complex state synchronization.

### What's New?

- **Action State**: Hooks like `useActionState` provide built-in status management.
- **Optimistic Updates**: Seamlessly update the UI before the server responds.
- **Progressive Enhancement**: Buttons and forms work even if JavaScript hasn't loaded yet.

This pattern is a game-changer for building robust, data-heavy applications with minimal overhead.
